
# The File Engine

This is the Engine which allows us to view and edit files directly. 

## The File Engine and Obsidian 

As I mentioned in [[The creation process of Rhizomeur]], some features can be piggybacked on Obsidian until they are made in Rhizomeur; I think that this is one of them. Obsidian already allows me to view and edit files with embedded images and all other sorts of fancy things that I don't want to deal with right away.

In my mind, I cannot currently imagine anything that I would want the File Engine to be able to do that Obsidian does not already do with its file editor.
