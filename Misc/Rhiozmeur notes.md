# Notes & Links 

## How notes and links relate to [[The theory of information - public]]

### The core concepts of notes (CCs)

As I explain in [[Representing KUs]], Notes represent KUs. Each KU represents a Note.(this sounds circular, but its' not: a Note is just the name I've given the `.md` files in the vault, but the notes which the KUs represent are concepts.) 

### Links

Notes are all connected by links. As I explain in my theory, links are all bidirectional. Most links will also have semantic meanings which will be described using the [[Logic Engine]]. 

## How links Notes and Links will be made 

In order to create the achieve bidirectional links and more complexe notes, I will be using a database (specifically a SQL Light database). The database will contain two tables:
1. **Links Table**
	- Unique Link Code
	- `.md` file with Unique Link Code
	- Logic
2. **Notes Table** 
	- Unique Note Code
	- `.md` file with Unique Note Code
	- Logic
