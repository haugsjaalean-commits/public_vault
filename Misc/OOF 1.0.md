## My thoughts on OOF 1.0

While the idea of trying to bring Rhizomeur to life in Obsidian is attractive, I don't it's realistic, at least not for right now. I see two ways for it to work out:
1. Basic implementation: basic query functionalities which enable me to create a KG-like structure. This would maybe "work", but it would be too slow and inefficient. This could still be an interesting proof of concept for [[My perfect KS|Rhizomeur]].
2. Complex plugin: If I create a very complex plugin to emulate [[My perfect KS|Rhizomeur]], I may find some efficiency, but I might as well just code Rhizomeur itself. 

For these reasons, I will opt out of this option for the time being and use only features that already exist in the app, which means straying quite far from the path of [[My perfect KS|Rhizomeur]].
