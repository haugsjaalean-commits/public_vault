
## What are knowledge systems?

A **knowledge system** (KS) needs to be able to do many things at once. This makes the creation of one very difficult.

The first function (and challenge) of a KS is that it needs to be able to create the units of knowledge. In order to create a KS, one needs to think of a method for describing units in a way that is efficient, and makes sense for the human mind.

The second function of a KS is that it needs to be able to restructure the KG (Knowledge Graph) at any moment and any level, and allow the user to move freely through the KG.

These two things alone pose many problems, and I think that one could devote their life to creating the perfect system. As of right now, we have nothing that comes even a little bit close to the thing that I'm describing.

## About knowledge systems


When creating knowledge systems, I believe that there is a certain way in which we need to be thinking about the KUs. Previously, I have considered that the KUs represent real-world things or concepts; however, I now believe this line of thinking to be flawed. The fact of the matter is that we are not organizing real-world things. We are organizing notes about real-world things. This is a key distinction, and will save us a lot of truble in the long run if we take the time to understand it. 

If we think about our KUs as representing the *things* themselves, then we risk forgetting what we are trying to organize is actually notes and note *things*. For this reason, I think that the best approach is to consider that the *core concepts* of the KUs are the very fact that they are a note which represents a thing.
