## New

Rhizomeur is built with three main levels. The goal of this is to keep things as modular, exponible, and flexible as possible. 
1. [[Rhiozmeur notes|Notes]] - This level is where the notes are described. As I have mentioned elsewhere, Notes are KUs which represent notes which describe things. In order to create this level, notes have to exist, and they have to have connexions to each other. These connexions will be described by a new language which I will create which will allow for queries involving semantic bidirectional links. This language will be created by the [[Logical Engine]]. And the ability to create the text of the notes and their links will be created in the [[File Engine]]. 
2. [[Rhizomeur Engines|Engines]] - Engines are the level which is used for transforming, displaying, and editing Notes. 
3. [[The interface of Rhizomeur|Interface]] - The Interface is what allows us to interact with the actions and capabilities given from the Engines.

To summarize this information, Notes are the definition of knowledge; Engines are what allow us to manipulate and visualize that knowledge; finally, the Interface is what allows us to interact with the Engines.
