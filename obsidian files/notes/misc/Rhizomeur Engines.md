
# Engines

Rhizomeur will function with multiple Engines. Each Engine represents a different way of displaying information (specifically discrete knowledge). Organization, the process through which we group, sort, and display objects, is the principle Engine, but there will be others too. 

The Engines will not be separate; quite the opposite, sometimes, they will be in constant communication with one another. The idea is that the different Engines will have a sort of synergy together. 

All Engines will be able to talk amongst each other. Some engines will be completely built on the backs of others. I think it helps to think of Engines as multiple parts of the same body. Different Engines

## Important question: reader and/or editor 

Will engines be for editing, or will they be *read only*? How could the Rhizomatic Engine be used to edit and create? 

It's settled, Engines will not only be used for viewing but also creating and editing! Some will be stronger than others for these purposes. 

I think that this will be a very interesting innovation. Instead of thinking about the text files as informing the graphs we create with them, we can think of it as a two way street. By changing the connexions in a graph, the data contained in tables and Notes will also change! This is amazing!!!
