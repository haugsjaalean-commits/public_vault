
# The Rhizome Engine



This Engine is--a little ironically--much less important than the Arborescent Engine is. I still think that it deserves a good amount of thought and attention, and I believe that, if it receives these things, it can be come a far more useful tool than I may think. 

## What is it? 


The Rhizomatic Engine is simply a graph showing the connexions between notes. This is exactly what the Obsidian graph is. This one, I hope, will be even more useful and flexible though. Of course, markdown links will look different from database links. I also want to include more three dimensional aspects to all parts of Rhizomeur, including the Rhizomatic Engine. I think that, while very cluttered when there are too many notes, a filtered Rhizomatic graph can be very useful. Luckily for us, we are already creating the ability to filter notes by using the [[Arborescence Engine]], so we don't even have to recode this function. 


## What can it be used for?

### Tracking backlinks

![[Rhizome Engine.png]]

As shown in the screenshot above, in Obsidian, I use the rhizomatic graph in order to track backlinks. One very cool thing is that I can color the Origin point red, so that I can see the quickest path needed to follow in order to get to the current file. I think this is one example of the usefulness of a rhizomatic graph.
